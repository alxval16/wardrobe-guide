# Как разобрать гардероб и перестать покупать лишнее

Статическая статья о разборе гардероба, новых сочетаниях и осознанных покупках.

Автор: Валерия Алексеева. Авторство фотографий, рисунков и скриншотов указано в статье.

## Просмотр

Откройте `index.html` в браузере или запустите из папки проекта:

```sh
python3 -m http.server 8000
```

Сайт доступен по адресу `http://localhost:8000`.

## Публикация на GitHub Pages

В настройках репозитория выберите **Pages → Deploy from a branch → main → / (root)** и сохраните.

## Состав

- `index.html` — статья;
- `styles.css` — оформление;
- `assets/` — изображения;
- `.nojekyll` — публикация статических файлов без обработки Jekyll.
